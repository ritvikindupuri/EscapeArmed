EscapeArmed 0.1.0  container escape readiness report

Targets

Summary
  CRITICAL 4  HIGH 4  MEDIUM 3  LOW 1  INFO 0

Findings
  CRITICAL EA001 Privileged container  (demo/docker-compose.yml:6)
           demo/docker-compose.yml#vulnapp: Container runs with --privileged.
           CVEs: CVE-2025-31133, CVE-2025-52565, CVE-2025-52881
           Fix: Remove privileged mode. Grant only the specific capability or device the workload needs.
  CRITICAL EA002 Dangerous Linux capability added  (demo/docker-compose.yml:29)
           demo/docker-compose.yml#sneaky: CAP_SYS_ADMIN added: mount, cgroup release_agent, many kernel interfaces.
           Fix: Drop ALL capabilities and add back only what is required. Never add SYS_ADMIN or SYS_MODULE.
  CRITICAL EA002 Dangerous Linux capability added  (demo/docker-compose.yml:8)
           demo/docker-compose.yml#vulnapp: CAP_SYS_ADMIN added: mount, cgroup release_agent, many kernel interfaces.
           Fix: Drop ALL capabilities and add back only what is required. Never add SYS_ADMIN or SYS_MODULE.
  CRITICAL EA003 Container runtime socket mounted  (demo/docker-compose.yml:11)
           demo/docker-compose.yml#vulnapp: Runtime socket /var/run/docker.sock mounted at /var/run/docker.sock (read-write). Read-only does not help, the API is still fully usable.
           Fix: Do not mount runtime sockets. Use a scoped API proxy or a dedicated build service instead.
  HIGH     EA004 Host root filesystem mounted  (demo/docker-compose.yml:12)
           demo/docker-compose.yml#vulnapp: Host / mounted at /host (read-only).
           Fix: Mount only the exact host directory the workload needs, read-only where possible.
  HIGH     EA006 Host PID namespace shared  (demo/docker-compose.yml:7)
           demo/docker-compose.yml#vulnapp: pid: host shares the host PID namespace.
           Fix: Remove pid: host / hostPID: true.
  HIGH     EA009 AppArmor disabled (unconfined)  (demo/docker-compose.yml:31)
           demo/docker-compose.yml#sneaky: AppArmor profile is unconfined.
           CVEs: CVE-2025-52881
           Fix: Use the default docker-default or runtime/default AppArmor profile.
  HIGH     EA013 Root in container without user namespace  (demo/docker-compose.yml:3)
           demo/docker-compose.yml#vulnapp: Process runs as UID 0.
           CVEs: CVE-2025-31133, CVE-2025-52565, CVE-2025-52881
           Fix: Run as a non-root USER, and enable user namespaces (rootless Docker, userns-remap, or Kubernetes hostUsers: false).
  MEDIUM   EA012 Host cgroup namespace or writable cgroupfs  (demo/docker-compose.yml:33)
           demo/docker-compose.yml#sneaky: Host cgroup namespace plus SYS_ADMIN makes release_agent reachable.
           Fix: Use a private cgroup namespace (the default on cgroup v2) and never mount cgroupfs read-write.
  MEDIUM   EA013 Root in container without user namespace  (demo/docker-compose.yml:25)
           demo/docker-compose.yml#sneaky: Process runs as UID 0.
           CVEs: CVE-2025-31133, CVE-2025-52565, CVE-2025-52881
           Fix: Run as a non-root USER, and enable user namespaces (rootless Docker, userns-remap, or Kubernetes hostUsers: false).
  MEDIUM   EA025 Writable host bind mount  (demo/docker-compose.yml:13)
           demo/docker-compose.yml#vulnapp: Host /tmp/escapearmed-demo-share mounted read-write at /shared.
           Fix: Mount host paths read-only, or use a named volume.
  LOW      EA014 no-new-privileges not set  (demo/docker-compose.yml:31)
           demo/docker-compose.yml#sneaky: no-new-privileges is not set.
           Fix: Set security_opt: no-new-privileges:true or allowPrivilegeEscalation: false.
